# 위임 패킷

역할은 `.codex/agents/<role>.toml`, 스킬은 `.agents/skills/<skill>/SKILL.md`다. runtime이 지원하면 등록된 역할로 호출한다. task_name/message만 지원하면 역할 파일과 스킬을 읽도록 message에 지정한다. 모델·권한은 상속하며 역할 호출을 이유로 바꾸지 않는다.

담당자에게 저장소/project·단계·목적/수용 조건·원본과 실제 캡처 경로/해시·허용 수정 경로·공통 계약·반환 형식을 준다. 순차 단계는 병렬로 시작하지 않는다.

비평가는 **새 인스턴스·새 컨텍스트**로 호출한다. 지원되는 컨텍스트 분리 옵션(예: fork_turns: none)을 명시한다. 검토를 다시 해도 이전 비평가를 재사용하지 않는다. 패킷은 다음 정보로 제한한다.

```text
역할: design_critic. 역할 파일과 design-critic SKILL.md를 읽는다.
저장소/project/검토 단계: 확정 값
요구사항·수용 조건: 원본 경로와 현재 해시
대상: 현재 JSON/CSV/HTML/SVG/Figma 노드와 실제 캡처 경로/해시
기계 검사: 현재 check/lint 결과와 검증 범위
권한: 읽기 전용, approve/review·사람 기록·원본 수정 금지
반환: ready/needs_revision/blocked, 위치·근거·영향·심각도·수정 제안·미검증
```

작성자 대화·설득문·“사용자가 좋아한 안” 같은 유도 문구·부모 판단·이전 비평 총평은 제외한다. findings처럼 검토 대상인 주장은 원본 캡처와 함께 포함한다. 이미지 보기/노드 조회 기능이 없으면 blocked/미검증으로 반환한다. runtime이 맥락 분리를 지원하지 않으면 독립 비평이라 표시하지 말고 새 세션이 필요하다고 보고한다.
