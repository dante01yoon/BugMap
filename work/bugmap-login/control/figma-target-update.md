# 정식 파일 키 등록

사용자가 제공한 BugMap URL을 공식 Figma 도구로 조회했다. 정식 키는 LynbxdW8Qf7TavCrPLd2nY, 페이지는0:1이며 보존 노드1:2·2:2·4:150·12:235·13:433과 위치/크기가 기존 브리지 응답과 일치한다.

과거 브리지 임시 키 local-mw921bod-gf4vt4는 명시 지정 조회에 실패하고 기본 조회만 성공했으며 상세 속성도 누락했다. 이제 실제 파일 키를 control/figma.json에 기록했다. 이전 설정은 control/history/figma-before-canonical-url.json에 보존했다. 승인/리뷰 로그를 수정하거나 승인자 대행을 하지 않았다.

공통 입력인 파일 식별자가 바뀌어 기존 PRD·wireframes·design-system 승인 해시는 현재 입력과 달라진다. 현재 승인된 디자인 원본을 변경하지 않은 상태에서 사람이 현재 대상 입력으로 세 게이트를 순서대로 다시 확인해야 한다.

재개 시 먼저 check를 실행한다. 정식 파일에서 아직 쓰기·새 프레임 생성은 수행하지 않았다.
