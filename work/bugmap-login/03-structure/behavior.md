## 로그인 요청 계약

- 세 제공자 텍스트는 식별자이고 `[공식 자산 자리]`는 저충실도 주석이다. 공식 로고를 그리거나 Lucide·문자 N으로 대체하지 않는다. 시스템 단계에서 공식 자산·48px 비율·한국어 레이블을 확인한다. 일반 UI 아이콘은 Lucide 기준을 따른다.
- default에서 제공자 선택 시 `selectedProvider`를 저장하고 단일 활성 요청 식별자와 잠금을 만든다. loading_kakao/naver/apple은 같은 배치의 선택 제공자별 메시지를 보여준다. 공식 버튼 레이블·로고는 스피너로 바꾸지 않는다. 회색 버튼은 렌더러 기본 스타일이며 실제 enabled/disabled 색을 정의하지 않는다.
- loading에서는 세 로그인 버튼 모두 disabled 및 접근성 비활성이다. 연타·다른 제공자 선택·앱 복귀가 새 요청을 만들지 않는다. 진행 메시지는 버튼 밖 live status에 제공한다는 명세다. 실제 접근성 발표는 미검증이다.
- 외부 인증 화면 뒤로/취소는 최종 취소 콜백이 확인되면 요청 잠금을 해제해 cancelled로 돌아온다. 오류 스타일 없이 중립 안내를 하고 세 선택을 다시 제공한다. 다음 선택은 새 요청이다. cancelled는 default의 안내 변형이다.
- 앱 복귀만으로 성공/실패를 추측하지 않는다. 동일 요청 콜백 대기 중에는 loading 유지, 오래된 콜백은 무시한다. 시간 초과 값과 SDK 오류 코드 매핑은 구현에서 정한다. 불명확한 대기를 임의 성공이나 미지원으로 처리하지 않는다.
- network_error는 예시로 카카오를 렌더했지만 다른 제공자에도 같은 템플릿을 적용한다. 메시지에 선택 제공자를 유지한다. 다시 시도는 이전 요청 종료와 잠금 해제 후 같은 제공자의 새 단일 요청이다. 다른 방법은 선택 상태를 지우고 default로 복귀한다. 제공자 버튼을 직접 고르면 해당 제공자로 새 요청한다.
- unsupported는 외부 입력 `supportStatus=unsupported`, 확인된 사유, 검증된 인증 환경을 받아 해당 제공자만 비활성화한다. Apple 예시는 실제 Apple 미지원 판정이 아니며 OS 이름만으로 상태를 만들지 않는다. 지원 여부가 미정이면 확인 흐름/SDK 확인으로 남기고 미지원 문구를 단정하지 않는다. 실제 제품에는 `이 인증 환경` 대신 검증된 구체 이유를 삽입해야 한다. 나머지 지원 제공자는 선택 가능하다.
- service_outage는 `supportStatus=temporarily_unavailable` 또는 확인된 장애 코드를 입력받아 잠시 중단을 알린다. 다시 시도는 지원정보를 갱신한 뒤 같은 제공자 요청, 다른 방법은 default로 돌아간다. 확정된 미지원과 다른 메시지·복구를 유지한다.
- success는 실제 인증·앱 세션 검증을 마친 콜백 뒤 기존 메인 지도로 이동하고 로그인 스택을 제거한다는 연결 명세다. 가상 성공 버튼은 만들지 않는다. success PNG는 검토용 도착 설명판이며 새로운 제품 완료 화면이나 실제 인증검증이 아니다.
- default에서 OS 뒤로는 플랫폼 기본 종료/백그라운드 규칙을 따른다. 이 화면은 루트라 앱 내부 이전 화면은 없다. 저장/편집 복귀는 이번 범위에 없다.

## 정책·접근성·보존

약관/개인정보 URL 및 동의 방식은 미정이다. LOGIN-06은 requirements.csv 문구뿐 아니라 승인 PRD 본문의 약관/개인정보 동작 위치·미정 표시 범위를 포함해 추적한다. 하단 두 슬롯은 명시적인 미연결 검토 표식이며 클릭·탭·키보드 초점·링크 role을 부여하지 않는다. 정책 링크가 확정되면 44px 이상 별도 보조 링크로 전환하고 외부 문서 뒤로에서 로그인 선택으로 복귀하도록 후속 명세한다. 지금은 링크/동의 완료를 주장하지 않고 policy_pending 비교판으로 미정을 보존한다.

읽기/초점 의도는 시각 순서와 같다. 상태 메시지는 live 영역, 복구 버튼은 메시지 다음, 진행 종료 후에는 원래 제공자 또는 오류 제목으로 초점 복구한다. 글자 확대·safe area가 예산을 넘으면 단일 세로 ScrollView로 전체 콘텐츠와 정책 슬롯에 접근시킨다. 로딩/오류가 생겨도 필수 선택과 정책을 가로 스크롤이나 고정 오버레이로 가리지 않는다. 실제 확대·스크롤·초점·인증·외부 링크 조작은 정적 저충실도에서 검증하지 않았다.
