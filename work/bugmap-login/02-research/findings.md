# 관찰과 해석 — bugmap-login

조회·직접 열람: 2026-11-13 KST. 대상은 처음 방문한 관찰·채집 사용자이며 과업은 서비스 목적 이해와 카카오·네이버·Apple 경로 식별이다. 이 문서는 정적 참조 연구이며 실제 인증 결과가 아니다. 캡처별 URL·해시는 sources.md / captures.json을 따른다.

## 현재 시안 baseline/1:2.png

- **직접 본 것:** 390×844 이미지. 흰 바탕, 초록 곤충/지도 일러스트, 큰 가치 제목, 하단 Google 행이 보인다. 그 위 회색 pill에는 읽을 수 있는 레이블이 없고 그 아래 작은 점이 보인다. 사진·지도 문구는 있으나 소셜 선택 영역을 완성된 세 제공자 UI로 읽기 어렵다.
- **가져올 점:** 지도와 기록의 연관을 보이는 상단 시각 → LOGIN-01 → 사진·위치 기록이라는 한 가지 가치만 짧게 전달한다.
- **피할 점:** 레이블 없는 pill·점 → LOGIN-02/06 → 빈 요소를 로그인 동작처럼 두지 않는다.
- **해석/미검증:** 실제 클릭·인증은 하지 않았다. 하얀 영역이 구현상 무엇인지는 이미지로 확정할 수 없다.

## 현재 시안 baseline/2:2.png

- **직접 본 것:** 원본은 390×884. 연보라 바탕, 상단 브랜드, 가로 소개 카드와 다음 카드 일부, 세 개의 큰 소셜 버튼, 이메일/비회원, 보안·가입 안내 pill, 작은 약관 문구가 보인다. 카드에는 실시간 지도·오늘 제보 42건·AI 일부, 카카오 버튼에는 3초, 안내에는 개인정보 암호화가 보인다.
- **가져올 점:** 세 제공자 행과 텍스트가 분리됨 → LOGIN-02 → 동일 폭·높이의 세 경로를 유지한다.
- **피할 점:** 수치·시간·보안 약속 및 주 동작처럼 보이는 미정 경로 → LOGIN-01/06 → 삭제하거나 검토 주석으로 분리한다. 주요 가치가 가로 카드 밖으로 밀리는 패턴은 첫 화면에서 필수 설명을 읽기 어렵게 할 수 있어 피한다.
- **해석/미검증:** 390×884는 목표 390×844와 다르다. 360×800 접근성·가로 스크롤·버튼 작동은 검증하지 않았다. 실제 원격 로고가 일반 기호로 보인다고 단정하지 않는다.

## Kakao — captures/kakao-official.png

- **직접 본 것:** 본문 중간에 노란 배경·검은 말풍선·레이블로 된 완성형/축약형 국문·영문 버튼, 아래에 Symbol/Label/Container 분해 그림이 보인다. 위쪽은 문서 헤더, 오른쪽은 목차다. 색상 표는 하단 경계에 일부만 보인다.
- **가져올 점:** 텍스트와 고유 심볼 결합 → LOGIN-02 → 공식 완성형 한국어 자산을 우선한다. 문서 본문에서 별도 확인한 색은 #FEE500, 검은 심볼, 85% 검은 레이블이다. 규정상 심볼 대체·변형을 하지 않고 폭 확장 규칙과 radius 12px를 따라 시스템의 pill과 예외를 둔다.
- **피할 점:** 일반 말풍선 기능 아이콘을 공식 심볼처럼 사용하지 않는다. 브랜드 노랑을 앱 전체의 강조색으로 넓히지 않는다.
- **해석/미검증:** 화면의 샘플 버튼을 인증 동작으로 누르지 않았다. 다운로드 자산/실제 48px 렌더 및 원본 수치의 배율 해석은 후속 시스템 단계에서 확인해야 한다.

## Naver — captures/naver-official.png

- **직접 본 것:** 상단 변경 안내에 #03A94D, 녹색 완성형 버튼의 흰 N·흰 레이블이 보인다. 아래 녹색/화이트 변형 예시와 표가 보인다. 화이트 변형의 실제 표는 Label #000000이고 보이는 레이블도 검정이다. 웹 추출 이미지 alt의 Label #FFFFFF와 다르므로 이 캡처에서는 픽셀과 표를 우선한다.
- **가져올 점:** 고유 N과 이름이 있는 완성형 → LOGIN-02 → 공식 PNG/Illustrator 자산과 최신 지정색을 사용한다. 문서 본문은 완성형 N 최소 16px와 가운데 배치 간격 8px, 왼쪽 배치 여백 20px를 안내한다.
- **피할 점:** 앱 초록으로 치환하거나 검색 아이콘·일반 텍스트 N으로 그려 대체하지 않는다. 공식 문구 예시에 시간이 있어도 우리 서비스의 가입 시간 근거가 되지 않는다.
- **해석/미검증:** 자산 다운로드·확대 픽셀 샘플링·인증은 미실행. 지정색과 화이트 변형의 표/alt 불일치는 후속 시스템에서 공식 파일로 재확인한다. 현재 추천은 모호성이 적은 녹색 완성형이다.

## Apple — 실패 보존과 대체

- **직접 본 것:** captures/apple-hig-incomplete.png는 Apple Developer의 상단 글로벌 메뉴만 보이고 본문은 검다. HIG의 버튼 배치나 형태를 본 근거로 사용하지 않는다. initial-capture-attempt.json에 당시 URL·해시가 보존돼 있다.
- **대체 캡처 직접 본 것:** captures/apple-official.png의 1280×4096 화면에서 Center-Aligned Buttons와 Left-Aligned Buttons의 검은 배경·흰 Apple 표식·“Sign in with Apple” 버튼이 회색 미리보기 영역에 보인다. 스타일/언어/크기 선택과 코드 예시가 있고 초기값은 English(US), 높이 32pt다. 상단 글로벌 메뉴는 CSS가 일부 적용되지 않은 듯 기본 링크로 보인다. 이 부분을 완전한 페이지 렌더라고 주장하지 않는다. 버튼 샘플 자체는 두 위치에서 확인했다.
- **가져올 점:** 공식 HIG의 별도 Markdown 본문은 시스템 버튼 우선, 다른 로그인보다 작게 하지 않기, 스크롤 없이 노출하기를 안내한다 → LOGIN-02/05 → 동일한 48px 높이로 세 경로를 한 묶음에 놓는다. 표준 흑백 버튼과 공식 자산을 사용한다.
- **피할 점:** HIG의 로그인 지연 권고를 이유로 비회원 동작을 새로 추가하지 않는다. 이번 승인 범위 밖이다. 로고를 임의로 그리거나 Smartphone 기호로 대체하지 않는다.
- **해석/미검증:** HIG 본문 시각 렌더는 미검증. 공식 HIG가 연결하는 appleid.apple.com/signinwithapple/button은 account.apple.com으로 이동한다. 대체 페이지 관찰은 아래 실행 검증 기록을 따른다. 실제 SDK·OS별 가용성·VoiceOver·로그인 취소/성공은 검증하지 않았다.
- **적용 한계:** 샘플 초기 32pt를 곤충맵의 터치 높이로 복제하지 않는다. 내부 수용 조건 48px를 유지한다. 한국어 선택·크기 슬라이더·다운로드는 조작하지 않았으므로 한국어 렌더 및 48px의 최종 로고 비율은 후속 확인 항목이다.

## 상태·정책에 대한 근거 한계

위 문서의 정적 화면에서 요청 중·취소·네트워크 실패·제공 불가 화면은 관찰하지 않았다. 이 상태가 없다고 결론내리지 않는다. recommendations.md의 복구 방식은 승인 LOGIN-03/04/09 및 TDD의 외부 인증 흐름을 구체화한 설계 제안이다. 이메일·비회원·약관 URL은 입력 문서에서도 미정이며 공식 제공자 문서가 곤충맵의 정책을 대신하지 않는다.
